# BUBAPC

### A Voice to Generations

**Busitema University Born Again Pentecostal Church (BUBAPC)** is a Christian fellowship for born-again believers—often called the *saved*—and Pentecostal students at Busitema University. Our desire is to grow together in faith, encourage one another, and share the message of Jesus Christ with our campus community and beyond.

**A Voice to Generations** expresses what we hope this fellowship will be: a place where today's students are strengthened in Christ and equipped to make a difference long after their time at university.

## About this website

This website is being developed to make information about BUBAPC easier to find and keep our fellowship connected. It brings together church updates, ministry information, and resources that can help members take part in the life of the fellowship.

The project is still in development. The sections below describe what the website is being built to support; some may not yet be complete.

## What you'll find

- **Our leadership:** information about pastors, church administrators, and elders.
- **Departments:** the teams serving in areas such as media, choir, ushering, and evangelism.
- **Families:** hostel-based fellowship groups where students can connect and grow together.
- **Events and programmes:** upcoming activities and the weekly fellowship schedule.
- **Daily devotionals:** encouragement and reflections from Scripture.
- **Church updates:** announcements and other information for members and visitors.

## Built with

The website uses a straightforward web stack:

- PHP for server-side functionality
- MySQLi with MariaDB/MySQL for data storage
- Bootstrap 5, HTML, CSS, and JavaScript for the interface
- nginx for local development and hosting

## Running the project locally

To work on the site, you'll need a PHP-enabled nginx server (PHP-FPM) and a MariaDB or MySQL database. Clone the repository into your web server's document root:

```bash
git clone https://github.com/HiswillKato/BUBAPC.git
```

Set up the database and application configuration according to the files included in the project, then open the site through your local nginx host. Configuration details may change as development continues. Keep database passwords and other secrets out of Git.

## Project status

BUBAPC is an ongoing project. I'm building it step by step, improving both the public pages and the tools used to manage church information.

## Purpose

More than an online noticeboard, the goal is to give the BUBAPC community a useful space to stay informed, participate in fellowship, and point others to Christ. It is made especially with born-again and Pentecostal students in mind, while welcoming anyone who wants to learn more about the fellowship.
